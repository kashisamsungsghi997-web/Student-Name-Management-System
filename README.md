# Project 2 — Student Name Management System

A simple Python project created to practice **Lists and While Loops**.

## Features

* Takes student names as input
* Stores names in a Python list
* Uses a `while` loop to add multiple students
* Uses `break` to stop the input process
* Uses `append()` to add names to the list
* Uses `enumerate()` to display students with serial numbers

## Concepts Used

* Python Lists
* While Loop
* If Condition
* Break
* Append
* Enumerate
* Input
* Print

## Example Output

```text
Enter Student Name = Peter
Enter Student Name = John
Enter Student Name = David
Enter Student Name = n

Saved Students:
1 . Peter
2 . John
3 . David
```

## Learning Goal

This project helped me practice **Lists and While Loops** together and understand how user input can be collected, stored, and displayed with serial numbers.
